# Proyecto sísmico de Jeremy

Este paquete corresponde al Proyecto Aplicado 2, tema 3, código C-03.
La carpeta de trabajo es `PROYECTO_2/C-03_FONSECA/`.

En VS Code, abrí esa carpeta y elegí una terminal WSL Ubuntu. Ejecutá:

```bash
bash iniciar.sh
```

El script entra a su propia carpeta, prepara el entorno e inicia Streamlit.
No necesita API key. Todos los cálculos se ejecutan en Python.

El `README.md` de esa carpeta explica las pruebas y cómo regenerar el informe.
El proyecto anterior de tarifas se mantiene separado.

Para entregar, copiá `PROYECTO_2/C-03_FONSECA/` dentro de TU fork del repositorio del curso.
El flujo `.github/workflows/pruebas.yml` va en la raíz de ese fork, donde GitHub lo ejecuta.
Si ya existe un archivo con ese nombre, conservá el existente y agregá este con un nombre propio.
No reemplacés carpetas de otros estudiantes.

Los documentos son un borrador calculado y revisable. Faltan acciones personales y externas:
crear el fork, mantener commits reales durante las semanas, publicar Streamlit,
completar los enlaces y revisar/firmar la declaración de autoría cuando corresponda.
