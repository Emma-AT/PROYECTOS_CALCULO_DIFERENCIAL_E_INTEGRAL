## Uso de las fuentes

El enunciado suministra las fórmulas de Gutenberg–Richter, el estimador de b, PAE y VPN y todos los datos del caso.
Las deducciones algebraicas y de integrales se desarrollan en este proyecto a partir de esas fórmulas.
OpenStax respalda el teorema fundamental y las reglas numéricas. Boore y NSMP describen
la sensibilidad de desplazamientos integrados a las correcciones de línea base.
La documentación de Streamlit respalda la comprobación de la interfaz.
No se atribuyen estos datos a registros oficiales de la CCSS, de la UCR o del USGS.
