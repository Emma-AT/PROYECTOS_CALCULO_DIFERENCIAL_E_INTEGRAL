# Matriz de lineamientos

| Requisito | Evidencia / estado |
|---|---|
| Pregunta de decisión y propuesta de una página | `informe/propuesta.pdf` |
| Base individual, lectura directa y conservación | `datos/`, `leer_base`, hash en `resultados/resumen.json` |
| Exploración, faltantes, atípicos, variables y unidades | `analisis.ipynb`, `docs/DICCIONARIO.md`, `BITACORA.md`, CSV de incidencias |
| Trapecio, Simpson e integral acumulada propios | `src/numericos.py` |
| Funciones mínimas específicas del proyecto | `src/modelo.py`, `src/limpieza.py`, `src/numericos.py` |
| b y demostración de la media de densidad | `MATEMATICA.md`, ficha y diapositivas |
| Acelerograma, v, x con/sin corrección | App y CSV de movimiento |
| PGA, PGV, PGD, Arias, duración | App y `resumen.json` |
| Probabilidades M≥6 y M≥7 en 50 años | App, ficha y resumen |
| PAE con Simpson y VPN | App, escenarios y CSV de verificaciones |
| Tres escenarios y sensibilidad b±0,1 y descuento | `src/escenarios.py` |
| Fórmula exacta y error relativo de integrales | `MATEMATICA.md` y `verificacion.csv` |
| Verificación doble seno <0,5 % | `validar_seno` y pruebas |
| Clase propia, docstrings, anotaciones, PEP8 | `BaseDatos`, funciones y ruff |
| Al menos ocho pruebas pytest | `tests/` |
| Gráficos rotulados, unidades y áreas sombreadas | `src/graficas.py`, app y `resultados/` |
| Caché, carga de otra base, CSV y tres controles | `app.py` |
| Cuaderno ejecutado | `analisis.ipynb` |
| Regenerar con python -m src.reporte | Tablas, figuras y PDFs desde la misma lógica |
| Ficha 4–6 páginas, APA y declaración | 5 páginas de ficha + declaración sin firmar |
| Resumen ejecutivo de una página | `informe/resumen_ejecutivo.pdf` |
| 10–14 diapositivas, marco teórico, 12–15 min | 13 páginas en `presentacion/diapositivas.pdf`, guion en docs |
| Workflow GitHub Actions | Preparado; debe colocarse y ejecutarse en la raíz del fork |
| Insignia de CI real | Pendiente de nombre de fork; generador `src.configurar_github` |
| Fork y 10 commits distribuidos en semanas | PENDIENTE de trabajo real en el repositorio del estudiante |
| Aplicación publicada y enlace comprobado | PENDIENTE de despliegue con cuenta del estudiante |
| Pull request antes de exposición | PENDIENTE de revisión y envío final |
| Autoría, comprensión y defensa individual | PENDIENTE de revisión, aprendizaje y exposición personal |

Una ejecución local exitosa no sustituye la publicación, la historia de desarrollo ni la defensa.
